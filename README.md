# Random Password Generator – Генератор случайных паролей

**Автор:** Милана Каракизова

## Описание
Приложение с графическим интерфейсом (Tkinter) для генерации случайных паролей с настраиваемыми параметрами.  
Возможности:
- **Ползунок длины пароля** (от 4 до 32 символов)
- **Чекбоксы** для выбора типов символов: цифры, буквы (A-Z, a-z), спецсимволы (!@#$%...)
- **Кнопка генерации** – создаёт пароль согласно выбранным настройкам
- Отображение сгенерированного пароля в текстовом поле
- **Копирование пароля в буфер обмена**
- **Таблица истории** всех сгенерированных паролей с датой/временем, длиной и использованными настройками
- Сохранение истории в JSON-файл (`history.json`) и автоматическая загрузка при запуске
- Кнопка **«Очистить историю»** с подтверждением
- Проверка корректности:
  - Хотя бы один тип символов должен быть выбран
  - Длина пароля находится в диапазоне 4–32 (ползунок сам ограничивает, но проверка дублирует)

## Требования
- Python 3.6+
- Стандартные библиотеки: `tkinter`, `random`, `string`, `json`, `os`, `datetime`
- Дополнительные установки не требуются
